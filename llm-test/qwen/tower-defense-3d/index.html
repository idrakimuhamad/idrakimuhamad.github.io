Instructions

Goal: Stop enemies from reaching your base. Survive all 20 waves.

Paths are dynamic: Enemies use A* pathfinding. There is no fixed road — towers you build change the route. You can never fully block the path; placement is rejected if it would wall off the base.

Building: Pick a tower from the bottom bar, then left-click a grass tile. Right-click or Esc cancels. Hover shows range and validity.

Towers: Click a placed tower to upgrade it (3 upgrades), change targeting (First / Last / Closest / Strongest / Weakest), or sell it for 70% of invested money.

Economy: Earn money from kills, wave bonuses, and starting waves early. Spend on towers and upgrades.

Controls: Left click / tap place/select · Right click cancel · Scroll or pinch zoom (toward the cursor) · Space start wave early · 1/2/3 speed · D debug · Esc pause / close / cancel.
